# Among the Microbes: Small Lives, Vast Worlds

เกมจำลองเชิงการศึกษาเรื่องแบคทีเรีย ไวรัส และ AMR (ข้อมูลทั้งหมดเป็น MODELLED / SYNTHETIC — ดู About ในเกม)

## รันใน VS Code
1. ติดตั้งส่วนขยาย **Live Server** (มีใน `.vscode/extensions.json`)
2. คลิกขวา `index.html` → *Open with Live Server*
ไม่มี build step: ทุกไฟล์ใน `js/` เป็น classic script ที่ใช้ global scope ร่วมกัน ลำดับใน `index.html` สำคัญ

## เล่นกับเพื่อนในเครือข่าย LAN
ต้องติดตั้ง Python 3 แล้วรันเซิร์ฟเวอร์จากโฟลเดอร์โปรเจกต์:
```powershell
py server.py
```
เปิด `http://localhost:8000` บนเครื่องโฮสต์ ส่วนเพื่อนที่ใช้ Wi-Fi/LAN เดียวกันเปิด `http://<IP-เครื่องโฮสต์>:8000` (หา IP ได้ด้วย `ipconfig`) แล้วกด **เล่นกับเพื่อน** และเข้าห้องด้วยรหัสเดียวกัน ทุกคนควรเล่นเกมและเข้า Lobby ผ่าน URL นี้เพื่อให้คลังการ์ดในเบราว์เซอร์ตรงกัน

โหมดเพื่อนปัจจุบันเป็นห้อง LAN สำหรับส่งอีโมจิและแลกการ์ดยีน ไม่ได้แชร์การควบคุมเกมหลัก เซิร์ฟเวอร์ไม่ต้องใช้ Firebase หรือแพ็กเกจเพิ่ม; ข้อมูลห้องอยู่ในหน่วยความจำและหายเมื่อปิดเซิร์ฟเวอร์ เหมาะกับเครือข่ายที่ไว้ใจเท่านั้น ไม่ควรเปิดพอร์ตสู่อินเทอร์เน็ต

## โครงสร้าง
| ไฟล์ | หน้าที่ |
|---|---|
| `js/config.js` | ค่าคงที่ (DATA_VERSION, reduced-motion, mute) |
| `js/data.js` | DB จำลอง: ประเทศ แหล่งอาศัย สายพันธุ์ ยา ยีน tier |
| `js/engine.js` | exact enumeration, AST, label, roll(), `__simulateRolls` |
| `js/store.js` | localStorage (`amb`) |
| `js/audio.js` | beep |
| `js/sprites.js` | วาดเซลล์พิกเซล, อารมณ์ตอบสนอง และเครื่องประดับซ้อนกัน |
| `js/codex_assets.js` | วาดไอเทมพิกเซล Research Journal และ Collection Card สำหรับ Codex |
| `js/ui.js` | หน้าแรกแบบไดนามิก, ใบแนะนำตัว, Codex, คลังยีนและข้อมูลเชื้อ |
| `js/life.js` | วงจรแบคทีเรีย 4 ช่วง หรือวงจรโฮสต์สำหรับไวรัส, HUD, อีโมต และบันทึกประจำรอบ |
| `js/events.js` | อีเวนต์เฉพาะเชื้อ และอีเวนต์ยาวแบบสุ่มที่มีมินิเกมกินจุด/ต่อบล็อก |
| `js/end.js` | จบรุ่น / แบ่งตัวของแบคทีเรีย หรือบันทึกผลวงจรไวรัส |
| `js/achievements.js`, `js/evolution.js` | 10 เหรียญตรา, 20 เครื่องประดับ (10 เริ่มต้น/10 ปลดล็อก), Evolution Card |
| `js/lab.js` | Sandbox Lab, Kaplan-Meier, Web Worker (fallback main thread) |
| `js/atlas.js` | Birth Atlas (แผนที่จุด) |
| `js/arcade.js` | Arcade 5 มินิเกม: เก็บอาหาร, กินจุด, ต่อบล็อก, จังหวะเซลล์ และภารกิจโรคสุ่ม |
| `js/pathogens.js` | Codex เรื่อง COVID-19, Ebola, plague, cholera, playable pathogen rolls และภารกิจสาธารณสุข |
| `js/main.js` | เรียก `home()` |
| `lobby.html` | ห้องแลกการ์ดยีนกับเพื่อนผ่าน LAN server |
| `server.py` | HTTP server แบบ Python standard library สำหรับเกมและห้อง LAN |

หน้าแรกสลับจุลชีพทุก 20 วินาทีและสุ่มอีโมตทุก 10 วินาที; คลิกตัวละครเพื่อโต้ตอบได้ทั้งหน้าแรกและระหว่างเล่น อารมณ์ตัวละครยังเลือกได้จากปุ่มในเกม สีแบคทีเรียแยกแกรมบวก แกรมลบ แกรมแปรผัน และชนิดที่ย้อมแกรมจำแนกไม่ได้ Codex มีภาพพิกเซลในหมวดหลัก คลังยีน เรื่องเล่าการระบาด และเหรียญตราความสำเร็จ 10 แบบ

ในการเริ่มเดินทาง ไวรัสรวมมีโอกาสสุ่ม 5% (SARS-CoV-2 4%, Ebola virus 1%) ส่วนอีก 95% เป็นแบคทีเรียจาก 14 สายพันธุ์ ในพูลแบคทีเรียแบ่งตามระดับความหายากในเกมเป็น Common 90%, Uncommon 9% และ Rare 1%; ภายในแต่ละระดับยังใช้สัดส่วนตามแหล่งอาศัยเดิม ตัวเลขทั้งหมดเป็นกติกาจำลอง ไม่ใช่ความชุกจริง ป้ายความหายากแสดงโอกาสพบสายพันธุ์ในเกม ไม่ใช่ความหายากของลักษณะ/ยีนหรือความชุกในธรรมชาติ SARS-CoV-2 กับ Ebola virus ใช้วงจรโฮสต์แยกต่างหากจากแบคทีเรีย (ไม่มี ATP หรืออีเวนต์ยาปฏิชีวนะ) ส่วน Yersinia pestis และ Vibrio cholerae อยู่ในพูลแบคทีเรียและยังมีอีเวนต์เฉพาะตัว สมุดภาพจุลชีพแยกหน้ารวมแบคทีเรียและไวรัส

Arcade รวม 5 มินิเกม: เก็บอาหาร, กินจุด, ต่อบล็อก, จังหวะเซลล์ และภารกิจโรคสุ่ม ในการเล่นจริงยังมีอีเวนต์ยาวแบบสุ่มที่เพิ่มมินิเกมเสริม 20 วินาทีให้ทำหรือข้ามได้ ภารกิจโรคสุ่มเลือก COVID-19 (SARS-CoV-2), Ebola, cholera หรือ plague โดย cholera และ plague เกิดจากแบคทีเรีย ไม่ใช่ไวรัส เป็นสถานการณ์จำลองเพื่อการเรียนรู้ ไม่ใช่การพยากรณ์หรือคำแนะนำทางการแพทย์

ใน Lab รายชื่อเชื้อแสดงเป็นชื่อวิทยาศาสตร์ภาษาอังกฤษ ส่วนคุณสมบัติเดิมของ Sandbox และ Kaplan–Meier ยังคงอยู่

มินิเกม outbreak เป็นสถานการณ์จำลองเพื่อการเรียนรู้ ไม่ใช่การพยากรณ์การระบาดหรือคำแนะนำทางการแพทย์ และหน้า Home ใช้คำโปรย “Small lives, vast worlds” แทนการอ้างจำนวนจุลชีพแบบตายตัว

## งานต่อที่แนะนำ
- แปลง global scripts เป็น ES modules (`import/export`) หรือใช้ Vite
- ปุ่ม TH/EN แปลแค่เมนู/หน้าแรก — แยกข้อความไปไฟล์ i18n
- ตรวจข้อมูล DB กับแหล่งจริง (WHO GLASS, CLSI/EUCAST, UN WPP) ก่อนตั้ง `verified:true`
